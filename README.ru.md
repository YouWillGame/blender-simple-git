# Simple Git Commit для Blender

[English version](README.md)

Небольшой аддон для Blender в одном файле: работа с Git прямо из программы. Коммиты, push, pull, ветки, переход между коммитами, клонирование и первая настройка репозитория с Git LFS.

> Интерфейс аддона пока только на русском.

## Возможности

- **Commit / Push / Pull** в боковой панели 3D-окна (`N` → **Git**). Push, Pull и клонирование выполняются в фоне и не замораживают Blender.
- **Ветки**: список, переключение, создание, переименование.
- **Коммиты**: выбор из последних 50 коммитов и переход на него (detached HEAD), затем создание ветки, чтобы продолжить работу отсюда.
- **Remote**: указать или обновить ссылку `origin` (GitHub, GitLab, свой сервер).
- **Init**: `git init` сразу с выбранным именем ветки (без `master`), с возможностью переместить открытый `.blend` в подпапку. 
- **Клонирование** репозитория в выбранную папку.
- **Setup**: создаёт или дополняет `.gitignore` и `.gitattributes` из встроенной базы (бэкапы вроде `*.blend1` игнорируются, `.blend`, текстуры и популярные 3D-форматы идут в Git LFS), выполняет `git lfs install` и убирает из индекса уже закоммиченные бэкапы `.blend1`/`.blend2`. Свои правила можно добавить в настройках аддона.

## Требования

- Blender 4.2 или новее (разрабатывался на Blender 5.3).
- [Git](https://git-scm.com/) в `PATH`.
- [Git LFS](https://git-lfs.com/) настоятельно рекомендуется для проектов с `.blend`.
- Для приватных репозиториев один раз авторизуйтесь из терминала или через Git Credential Manager: Blender не умеет отвечать на запросы пароля.

## Установка

1. Скачайте `git_commit_addon.py` из [последнего релиза](../../releases/latest).
2. В Blender: **Edit → Preferences → Add-ons → Install from Disk** (в Blender 4.2+ это выпадающее меню справа вверху) и выберите файл.
3. Включите галочку **Simple Git Commit**.
4. В 3D-окне нажмите `N` и откройте вкладку **Git**.

## Быстрый старт

1. Сохраните .blend файл.
2. Откройте **Новый репозиторий** → **Init репозиторий**, либо **Клонировать**, если репозиторий уже есть.
3. Нажмите **Setup**, чтобы создать `.gitignore` / `.gitattributes` и включить LFS.
4. Откройте **Удалённый репозиторий**, вставьте ссылку и нажмите **Привязать**.
5. Введите сообщение, нажмите **Commit**, затем **Push**.

## Работа с .blend файлами

`.blend` это бинарный формат: Git не умеет сравнивать и сливать его, поэтому два человека не должны править один файл одновременно. Разбейте проект на несколько файлов (Link / Library Overrides) и подумайте о блокировках Git LFS (`lockable` в `.gitattributes`).

## Ограничения

- Нет слияния, разрешения конфликтов, индекса по файлам и графа истории (используется `git add -A`).
- Commit выполняется синхронно, поэтому очень большой коммит может надолго занять Blender.
- После Pull или переключения ветки/коммита откройте .blend заново, если файл на диске изменился.
